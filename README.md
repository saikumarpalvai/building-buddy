# Building Buddy
 
**Build real projects, together.**
 
## Why Building Buddy exists
 
Building Buddy exists to help students and self-learners
start building real software projects even when they don’t
know where to start or whom to build with.
 
Many platforms focus on solving problems or watching tutorials.
Building Buddy focuses on learning by building real projects.
 
## Core principles
 
- Learning happens by doing
- Copying is allowed; understanding comes over time
- No certificates or job guarantees
- Solo and team learning are both valid
- Real projects matter more than completion speed
 
## Current status
 
This is the first version of Building Buddy.
It is intentionally simple and focused on clarity.
